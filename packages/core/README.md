# @marcusrbrown/anthropic-auth-core

Shared Anthropic OAuth, quota, cache, cache-keepalive, fast mode, relay, dump, and request-signing helpers used by CortexKit's OpenCode and Pi integrations.

This package is published in the `marcusrbrown` fork as `@marcusrbrown/anthropic-auth-core`. The upstream CortexKit package is `@cortexkit/anthropic-auth-core`.

User-facing packages:

- `@marcusrbrown/opencode-anthropic-auth` for OpenCode (fork, published at `1.2.2-mb.2`)
- `@cortexkit/pi-anthropic-auth` for Pi (upstream CortexKit, not published in this fork)
