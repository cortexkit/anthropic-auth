# anthropic-auth 2.5.7

## Fixes

- **A host that exits in the middle of taking a lock can no longer slow the next start.** Uses common-auth 0.39.1, which writes each lock file and its owner record in one atomic step on Linux and macOS. Before, a host that crashed or exited at the wrong moment could leave an empty lock file. A host started within the next 10 seconds could then wait on it, and one vault account-list refresh or settings change could fail. Windows is unchanged.

## Internal

- Runner turn notes are now read through common-auth's shared reader. Nothing changes for users.
- Build scripts accept npm 12's `npm pack --json` output.
