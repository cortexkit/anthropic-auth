# anthropic-auth 2.5.8

## New

- **Per-attempt token usage on safety-fallback steps (OpenCode 1 and 2).** When Anthropic's server-side safety fallback answers a request, the usage it reports is the billed sum of both attempts. OpenCode stores that sum as the step's tokens, so tools that size the conversation from it saw about twice the real context, and could compact early. Each fallback step now also stores a hidden reasoning part with the per-attempt usage. Billed totals and what is sent to Anthropic are unchanged. See "Per-iteration usage" in `docs/request-rewriting.md` for how to read it. Addresses #648.
