# anthropic-auth 2.5.3

## Fixes

- **OpenCode 2: a reply cut off by a dropped connection now continues.** When the connection drops after Claude has started answering, OpenCode 2 continues the reply on the same account instead of ending the turn. It does so only when that account is unchanged and can still serve the request under your quota floors, killswitch and model limits. Otherwise the turn ends as before. Uses common-auth 0.36.0.
- **Pi: a refused request now says why.** When Claude refuses a request, or ends it with a stop reason the plugin doesn't know, Pi now shows an error naming the reason, for example `Claude refused this request (stop_reason: refusal, category: cyber).`, instead of ending silently with no message. The plugin also writes one warning to its log with the stop reason, category, model and session. Neither the message nor the log ever includes the explanation text Anthropic returns, because it can repeat your prompt.

## Dependencies

- common-auth 0.36.0 (was 0.35.0).
