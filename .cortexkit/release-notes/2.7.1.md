## anthropic-auth 2.7.1

### Fixes

- **Vault mode no longer polls Anthropic's usage endpoint when Insula already has the reading.** The plugin refreshed its copy of Insula's quota readings only every 5 minutes but treated readings older than 4 minutes as stale, so between refreshes a request could fall back to polling Anthropic itself. The copy now stays current from Insula's own updates, with a once-a-minute refresh when those aren't available. Requests never wait on either ([#673](https://github.com/cortexkit/anthropic-auth/issues/673)).
- **The log records hosted mode.** When Thalamus starts the host and the plugin reads accounts through Thalamus's vault relay, the log now says so once per process.

Still on common-auth 0.42.0.
