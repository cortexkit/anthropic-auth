# anthropic-auth 2.5.6

## Changes

- **Pi keeps warming its prompt cache across a Pi restart, like OpenCode 2.** Until now, Pi kept its keep-warm list only in memory. A restarted Pi that then sat idle for more than an hour lost its prompt cache, even when nothing in the conversation had changed. Pi now saves each warmed session the way OpenCode 2 has since 2.4.5: gzipped, owner-only, with no headers or credentials, under `~/.local/share/cortexkit/anthropic-auth/cachekeep-restore/pi/` (`%USERPROFILE%\.local\share\...` on Windows, or under `$XDG_DATA_HOME`). It picks the session up again as soon as it starts, before any new message.
  - Each Pi process restores only the session it is running, and two Pi processes never warm the same session.
  - Restoring happens in the background, so a turn never waits for it.
  - OpenCode 2's saved files keep the same format and location, now through shared code.
