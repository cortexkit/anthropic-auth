## Changes

- **Faster, more reliable setup on Windows.** Setup checks that OpenCode and Pi are stopped before it changes anything. That check could take over 45 seconds on Windows ARM, so setup refused to run. Setup now uses PowerShell 7 when it's installed, which makes the check take under a second. Without PowerShell 7, ARM machines get more time and a message saying the check can take up to a minute.
- **Setup checks for running hosts far fewer times.** A check still runs right before every change setup makes, and after every wait. Setup no longer repeats a check when nothing has happened since the last one. This speeds up setup on every system.
- Updated the shared authentication library to common-auth 0.52.0.
