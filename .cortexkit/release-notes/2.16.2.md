## Fixes

- **OpenCode 1: a response no longer waits for the sidebar to be updated.** After choosing an account, OpenCode 1 used to re-read the account file and write the sidebar before handing the model's response back. That work now runs in the background, in order, and is flushed when OpenCode shuts down.

## Changes

- **Vault accounts with an unknown sign-in method are ignored.** A vault login whose method the plugin doesn't recognise, such as a gateway login, is never listed, used or routed as a Claude subscription login. Today's vaults don't produce such logins; this guards against future ones.
- **Dependency updates:** common-auth 0.55.1, claustrum-client 0.20.0, subc-client 0.24.5, the OpenCode 2.3.0 plugin with its OpenTUI and Solid versions, Pi 1.5.2 packages, the shared OpenCode sidebar 0.3.0, the Anthropic AI SDK, Biome, clack and babel.
