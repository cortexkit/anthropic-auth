## Fixes

- **OpenCode 2: a dropped connection during a thread resend is retried.** When Anthropic rejects a message-thread request, the plugin resends it in full. If the connection dropped during that resend, OpenCode 2 didn't recognise the failure as a dropped connection, so it ended the turn with an error instead of retrying. It is now retried like any other dropped connection, and the retry goes out in full. OpenCode 1 and Pi already retried it. (#613)

## Dependencies

- The OpenCode TUI now uses OpenTUI 0.8.1 with solid-js 1.9.18. OpenCode 2.2.3 and later require OpenTUI 0.8 or newer; a real OpenCode 2.2.0 host still loads the plugin.
- The OpenCode 1 test host is 1.19.5, and the Anthropic SDK, Babel, Biome and mise-action are updated.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
