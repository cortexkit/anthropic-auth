# anthropic-auth 2.5.5

## Fixes

- **OpenCode 2: keep-warm keeps working after a plugin reload from 2.5.2 or 2.5.3.** A running OpenCode 2 server that reloaded the plugin to 2.5.4 kept the older keep-warm manager, as designed, so tracked sessions carry over. But 2.5.4 then called a method that only exists in its own manager. Requests still worked, but every tracked reply logged "live request tracking failed", and the keep-warm session list stopped updating until OpenCode restarted. The plugin now falls back to what the older manager supports. The new session-list location and fields take effect after the next server restart. Addresses #637.

## New

- **Turn-scoped notes from a CortexKit session runner.** When OpenCode 1, OpenCode 2 or Pi runs under a CortexKit session runner that supplies notes, the plugin inserts each note right after the tool result it belongs to, as a turn-scoped system message. Today that's Magic Context reminders under Thalamus. A note appears only on Claude subscription routes and models that support turn-scoped messages. Without a runner, requests are unchanged.

## Dependencies

- common-auth 0.38.0 (was 0.37.1). No change users see.
