## anthropic-auth 2.7.2

### Fixes

- **Keep-warm sessions survive the upgrade to 2.7.** On the first OpenCode 2 or Pi start after upgrading to 2.7, keep-warm sessions saved by 2.6 or earlier were all dropped when keep-warm was set to "always", so each idle one paid a full cache rewrite later. They're now kept warm, and the limit of 24 warms without a real request counts from the restart ([#677](https://github.com/cortexkit/anthropic-auth/issues/677)).
- **Server-fallback boundaries survive context clearing.** If a context manager replaced the text of the hidden marker that records where Anthropic's safety fallback took over, the plugin no longer recognized it and sent it to Anthropic as an invalid thinking block. It's now recognized by its signature alone and restored to Anthropic's exact fallback block.

Still on common-auth 0.42.0.
