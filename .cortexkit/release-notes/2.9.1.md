## Fixes

- **A Claude reply that stops early no longer ends the turn silently.** If a response stream ended before Claude's final event, Pi stored it as an empty normal reply, so the agent's turn ended and the model never answered. Pi and OpenCode now treat such a stream as a dropped connection and retry it. An explicit error from Anthropic or the relay still reaches you unchanged. Each such case logs one warning with Anthropic's request ID, the bytes and events received, and the timing (no prompt or reply text), so the cause can be traced.

## Internal

- Updated the shared auth library (common-auth 0.43.0). The OpenCode sidebar now draws from the shared `@cortexkit/opencode-sidebar` package, with byte-identical output. Vault setup's connection names and vault connection recovery now go through the shared library.
