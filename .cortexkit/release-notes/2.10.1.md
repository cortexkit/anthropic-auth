## Fixes

- **OpenCode 1: going back to the original model after an Opus recovery round works again.** If a recovery round started in the middle of a turn, the next request to the original model (for example Fable 5.2) could be refused every time with "thinking blocks cannot be modified". The plugin now leaves the recovery round's Opus thinking out of that turn, including after OpenCode restarts.
- **OpenCode 2 under Thalamus: billing reports keep unique ids across restarts.** After a server restart, reports reused earlier ids, and Thalamus dropped them as repeats.
- **OpenCode: an unconfirmed rate limit is no longer reported to shared routing as a weekly limit.** Only limits the response headers confirm are reported.

## Changes

- **Pi under Thalamus:** each answer now records Anthropic's response id, so Thalamus can match Pi's billing reports to their transcript rows.
- **Pi under Thalamus:** Pi now sends confirmed account limits and successful requests to Thalamus's routing relay. Routing acts on them once Pi also asks routing which account to use, in a later release. Until then they have no effect.
- **OpenCode 2 and Pi under Thalamus:** each completed model request now says whether keep-warm is on for the session, or why it stopped.
- **Pi:** when a Claude stream is cut short, the plugin now records how many compressed and decompressed bytes arrived, to help diagnose empty responses. Pi also sends the same response-compression preferences as Claude Code.
- Dependency updates.
