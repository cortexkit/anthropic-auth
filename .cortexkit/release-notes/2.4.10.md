## Fixes

- **Shared routing pool names (CortexKit agent runner only).** A used-up model limit is now reported to shared routing with its pool name in routing's lowercase form (for example `fable`). A model limit whose name routing cannot accept is not reported at all, so it is never mistaken for the whole account's weekly limit. Without the runner, nothing changes.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
