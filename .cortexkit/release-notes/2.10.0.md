## New

- **Claude Mythos 5.2.** It's in the model picker, with all effort choices and its own prices and limits. Its requests use the same settings as Mythos 5.1, since nothing yet shows that Mythos 5.2 accepts Fable 5.2's extra options. The default effort is high, as on Anthropic's model page. On OpenCode 2, Mythos 5.1 shows its effort choices again. Both Mythos models now send the preserved-thinking binding control, so a history edit drops old thinking instead of failing the request. (#697)
- **One approval grants access.** On vaults that support it, approving the plugin in the vault now also grants it read access to your Claude accounts, so setup no longer needs a separate `ck auth grant`. If you approve the plugin but decline the grants, setup respects that and doesn't grant access itself. Older vaults keep the separate grant step.
- **Billing reports under Thalamus.** OpenCode 2 and Pi hosted by Thalamus now report each real Claude request's paying login and token usage, including failed attempts and keep-warm requests, to Thalamus's spend records. Nothing is reported outside Thalamus.

## Fixes

- **Keep-warm with signed thinking.** Keep-warm requests for conversations that replay signed thinking were refused by Anthropic, because a required beta was missing. Those sessions stopped being kept warm and paid a full cache rewrite. The beta now goes with every request whose body needs it. (#696)
- **Keep-warm after a routing change.** Keep-warm no longer warms an idle session on its old account when routing would send the session's next turn to a different account. That happened after a routing mode change, or when quota moved ordered routing. Those warms cost money and were never read. The plugin now stops warming such a session and logs `routing-moved`. A sticky-balanced session still pinned to its account keeps warming. (#698)
- **Returning from an Opus 4.8 recovery round (OpenCode 1).** After a refused reply, the first request back to the original model now finds the cache that model left behind, instead of rewriting most of the prompt. Source keep-warm now keeps the last request Anthropic actually accepted with cache, not the refused one.
