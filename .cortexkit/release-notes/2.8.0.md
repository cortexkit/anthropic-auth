## Claude Fable 5.2

- **Fable 5.2 support:** Adds Claude Fable 5.2 (`claude-fable-5-2`) on OpenCode 1, OpenCode 2 and Pi.
- **Request shape:** requests are sent the way Claude Code sends them, with adaptive thinking, medium default effort, per-message effort and Anthropic's safety fallback.
- **Prices:** $8 input, $40 output, $0.20 cache read, and $10 or $16 for 5-minute or 1-hour cache writes, per million tokens.
- **Fast mode:** stays off for Fable 5.2 until Anthropic enables it for subscription accounts.
- **OpenCode 2 model picker:** Claude models the plugin supports but OpenCode's own model list doesn't have yet now appear in the picker, as they do on OpenCode 1. That's how Fable 5.2 shows up on launch day. Models OpenCode already lists keep their own entries.

## Other changes

- **Subscription request shape:** Claude subscription requests no longer carry a `service_tier` field a host adds, which keeps them in the shape Claude Code sends. API-key requests keep it.
