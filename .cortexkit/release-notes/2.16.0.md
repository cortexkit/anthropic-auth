## New

- **Opt-in `wait_for_reset` setting.** When every Claude account is out of quota and the reset time is known, the plugin can now wait until the reset and then continue the turn on its own, instead of rechecking every 15 minutes. It's off by default; set `wait_for_reset: true` in the shared settings file (`anthropic-auth.jsonc`) to turn it on. It works on OpenCode 1, OpenCode 2 and Pi. It only applies when no account at all can serve the request: with several accounts, routing between them works exactly as before. On OpenCode 2 a turn already running waits for the reset; a new message sent while every account is already out of quota still stops at once and says when to send it again. See the [settings file docs](https://github.com/cortexkit/anthropic-auth/blob/main/docs/settings-file.md#wait-for-a-quota-reset). ([#818](https://github.com/cortexkit/anthropic-auth/issues/818))

## Changes

- **OpenCode 2 can use all ten of its retries for quota waits.** Before, the last two retries could not be used to wait, so a turn waiting out a quota limit stopped about 30 minutes early.
- **Pi: connecting to the vault deletes Pi's own saved Claude sign-in.** Disconnecting no longer brings it back. Sign in again after disconnecting if you want to use Pi without the vault.
