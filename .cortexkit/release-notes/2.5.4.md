# anthropic-auth 2.5.4

## Fixes

- **OpenCode 2: much less file reading while idle in vault mode.** The plugin read and fully decoded its state file about twice a second, and the vault account list about as often, even when neither had changed. Both are now reused while the file is unchanged. Ownership and permission checks still run on every read, so a file whose owner or permissions change is still refused. In a traced run, 72 idle checks plus two requests went from 87 account-list opens to none. Addresses #627.

## Changes

- **The keep-warm session list is now a stable, documented file.** Other local tools can read it to tell whether a session's prompt cache is still warm. See the new page `docs/cachekeep-registry.md`. Addresses #592.
  - It moved from the system temp folder to `~/.local/share/cortexkit/anthropic-auth/cachekeep-sessions/` (`%USERPROFILE%\.local\share\...` on Windows, or under `$XDG_DATA_HOME` when set). For this release the plugin also writes the old temp location, so older processes still see it.
  - Each session now also lists the cache lifetime actually used, the time of its last cache refresh, and, when keep-warm stops, when and why. A stopped session stays listed until its cache expires.
  - OpenCode 2's keep-warm restart records also moved to `~/.local/share/cortexkit/anthropic-auth/cachekeep-restore/`, so a computer restart no longer deletes them. They are loaded once from the old temp location on update.

## Dependencies

- common-auth 0.37.1 (was 0.36.0).
