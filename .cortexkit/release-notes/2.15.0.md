## Changes

- **OpenCode 2 stops on an account that is out of quota.** It no longer sends more requests to an account Claude has just confirmed is out of quota. When no account has room, the turn ends with a message naming the limit and when it resets. Before, newer OpenCode versions could retry the same account several times, and local mode showed a misleading "repair the pool" message.
- **Pi prices one-hour prompt-cache writes correctly.** Pi priced every cache write from this plugin as a five-minute write. The one-hour part is now priced at the one-hour rate, so Pi's cost display is accurate.
- **Pi can answer forked questions for Agent Runner.** Agent Runner can ask a Pi agent a side question while the agent works, such as during a phone call. The question uses the same Claude account and prompt cache as the agent, and changes nothing in the agent's own session. It can also run at a lower effort for a faster answer, without losing the cache. This only takes effect when Agent Runner turns it on.
- **`/claude` Status says why the settings move waits.** When the one-time move to the shared settings file has not run, Status and the log now say that the old settings are in use and what the move is waiting for.
- **The settings move no longer waits forever on leftovers.** Unreadable files that an earlier plugin version left behind stopped the one-time settings move from ever running. Now such a file is ignored when its plugin process is gone or the file is older than the last restart of the computer. Anything uncertain still holds the move back.
