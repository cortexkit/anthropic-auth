## Fixes

- **No more hours-long silent waits on usage limits.** When every Claude account was at a usage limit, the plugin could pass on Anthropic's own retry time to OpenCode, and the session then waited silently for many hours (one waited 26 hours). The plugin now never tells OpenCode 1, OpenCode 2 or Pi to wait more than 15 minutes, and checks again then. The error message names the limit that blocks the request and the earliest reset time in UTC. On OpenCode it says it retries every 15 minutes. On Pi, which doesn't retry this error by itself, it says to send the message again after the reset. The retries are refused locally until an account has room, so they cost no Anthropic requests.
