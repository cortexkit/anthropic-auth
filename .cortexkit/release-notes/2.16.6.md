## Changes

- **Pi: changing thinking effort mid-conversation keeps the prompt cache.** On models that support per-message effort, an effort change is now sent as a per-message marker at the point where it took effect, and the request's top-level effort stays the same. Before, Pi moved the top-level effort twice for one change, once within the same turn and again at the next turn, and each move rewrote the cached conversation. This also works when a context manager such as Magic Context shortens the conversation Pi sends.
- **Four more models keep the prompt cache when effort changes mid-conversation.** On OpenCode 1, OpenCode 2 and Pi, Claude Haiku 5.5, Mythos 5.2, Opus 5 and Mythos 5.1 now receive an effort change as a per-message marker, as Fable 5.1, Fable 5.2, Opus 5.5 and Sonnet 5.5 already did. These are the eight models Anthropic lists for per-message effort. Haiku 5.5 and Opus 5 use it only with adaptive thinking; requests with thinking turned off are unchanged.
