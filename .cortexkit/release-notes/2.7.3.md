## anthropic-auth 2.7.3

### Changes

- **Vault setup names the plugin.** When setup asks the credential vault for access, it now proposes a readable name: "Claude sign-in for OpenCode" or "Claude sign-in for Pi". The vault's approval prompt and the apps' Permissions page show that name. An older vault that doesn't know the field is asked again without it.
- **Dependencies:** `@cortexkit/claustrum-client` 0.17.0 and `@cortexkit/subc-client` 0.24.

### Diagnostics

- **Request dumps record reply text edges.** With request dumps on, each streamed reply's response summary now includes `reply_text_edges`: for each text block, the count of leading and trailing whitespace characters and the total characters. It holds counts only, never text. Pi now also writes a response summary for ordinary requests, not just keep-warm ones.

Still on common-auth 0.42.0.
