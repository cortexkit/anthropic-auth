## Changes

- **OpenCode 2: steadier retries.** Once a reply has started showing output, a later retry of that same request stays on the same account, or stops with the provider's error, instead of quietly replaying on another account. A refused title or compaction request no longer decides how the main request is retried. This comes from common-auth 0.56.3.
- **Dependency updates:** common-auth 0.56.3 and claustrum-client 0.21.0. The new vault "login condition" calls they add are not used by this plugin.
